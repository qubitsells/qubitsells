# The Midnight Key

A second cozy Halloween couples story, created with built-in image generation. Six text-free original Disney-inspired 3D illustrations, preserving the adult couple and costumes from Pumpkin Moon Date.

## Story order

1. **The hidden key** — A tiny discovery starts their Halloween adventure. `01-the-hidden-key.png`
2. **Follow the fireflies** — They follow a glowing trail across a little bridge. `02-follow-the-fireflies.png`
3. **The secret garden gate** — Their key opens a path into the garden. `03-the-secret-garden-gate.png`
4. **A treasure around the corner** — A playful garden maze leads them to a hidden chest. `04-a-treasure-around-the-corner.png`
5. **The heart of the adventure** — The treasure is a glowing heart they discover together. `05-the-heart-of-the-adventure.png`
6. **Dancing under a Halloween moon** — Their adventure ends with a quiet dance beneath the moon. `06-dancing-under-a-halloween-moon.png`

## Contents

- Six numbered PNGs.
- `preview.html`: local sequence viewer. Extract this entire folder before opening it.
- `PROMPTS.md`: human-readable image and optional animation prompts.
- `image-prompts.json`: complete generation prompts and reference roles.
- `video-prompts.json`: six optional image-to-video prompts; videos have not been generated.
- `sequence.json`: asset order, timing and suggested application copy.
- `IDE_PROMPT.txt`: copy-ready implementation instructions for the Bonded app.

## Image size

Native PNGs are 1672 x 941, approximately 16:9. The preview displays an exact 16:9 frame with object-fit:cover. No post-generation cropping or resizing has been applied to the PNGs.

## Continuity and use

All six scenes use the same approved Halloween couple as an image reference. Keep faces, hair, costumes and proportions fixed when regenerating. Generated decorative, background and prop details can vary slightly; crossfades are appropriate, but these stills do not guarantee seamless geometric interpolation.

The story uses a key, lantern, iron gate, chest and glass heart as recurring motifs. Scene 4 keeps the chest closed; scene 5 reveals its heart; scene 6 shows the closed chest with heart and key on top. No text is embedded in the artwork. Render names, messages and actions separately in HTML.

The preview is a local media viewer. Real saved replies, paired profiles and confirmed plans need the existing app's supported flows, as described in the IDE prompt.
