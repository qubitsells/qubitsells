# The Haunted Waltz

A six-scene original 2D gothic horror-romance template for couples who enjoy haunted houses, ghosts and spooky stories. Created with built-in image generation.

## Story order

1. **The manor at midnight** — A couple approaches a haunted manor, with two figures watching from an upstairs window. `01-the-manor-at-midnight.png`
2. **Footsteps with no owner** — Ghostly traces lead the couple deeper into the house. `02-footsteps-with-no-owner.png`
3. **The ghosts in the ballroom** — Two spirits appear as if waiting for their last dance. `03-the-ghosts-in-the-ballroom.png`
4. **Stay close to me** — They steady each other and choose to face the mystery together. `04-stay-close-to-me.png`
5. **The haunted waltz** — The living couple joins the spirits for a final waltz. `05-the-haunted-waltz.png`
6. **Until the last candle** — At dawn, they leave with a memory only the two of them understand. `06-until-the-last-candle.png`

## Contents

- Six numbered text-free PNG illustrations.
- `preview.html`: local sequence viewer. Extract this entire folder before opening.
- `CHARACTERS.md`: living and ghost cast, wardrobe, atmosphere and reference rules.
- `PROMPTS.md`: human-readable scene-generation and animation prompts.
- `image-prompts.json`: complete generation prompts with reference roles.
- `video-prompts.json`: six optional five-second image-to-video prompts. Videos have not been generated.
- `sequence.json`: asset order, dimensions, timing and suggested HTML copy.
- `IDE_PROMPT.txt`: implementation request for the Bonded app.

## Size and playback

PNGs are 1672 x 941, approximately 16:9. The preview displays an exact 16:9 viewport with object-fit:cover. No image cropping, resizing or retouching was applied after generation. Suggested continuous edited timing: five seconds per scene, 500ms overlapping fades, 27.5 seconds total.

## Continuity and interaction

Scene 1 established the living couple, manor, lantern and style; the following scenes used it as an image reference. The ghost couple is introduced in scene 3 and returns in the remaining story. The sequence has consistent main designs, though generated decorative and background details can vary slightly between stills.

Keep names, personalized messages, date choices and replies as separate HTML. The local preview only shows media; real saved replies and confirmed plans require the existing app's supported integration. Suggested final invitation: choose a horror movie night, haunted-house date or ghost-story evening, then agree on a time.
